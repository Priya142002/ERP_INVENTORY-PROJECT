# ERP_INVENTORY - Plug-and-Play ERP Frontend

A professional, modular, and fully responsive ERP system frontend built with React and Vite. This project is designed with a **Plug-and-Play architecture**, allowing any backend to be integrated seamlessly in the future.

## 🚀 Features
- **Modular Design**: Each module is self-contained.
- **Pure Frontend**: No backend, database, or API dependencies.
- **Mock Data**: Pre-populated with realistic business data.
- **Premium UI**: Sleek dark mode, smooth animations, and Inter typography.
- **Responsive**: Full support for Desktop, Tablet, and Mobile.

## 📦 Modules Included
- **Admin**: User management and system health monitoring.
- **Accounts**: Financial tracking, revenue, and expense management.
- **Inventory**: Stock levels, warehouse management, and low stock alerts.
- **Purchase**: Vendor management and procurement workflows.
- **Sales**: Invoice management and revenue analytics.

## 🛠️ Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Routing**: React Router DOM (v6)
- **Styling**: Vanilla CSS (Modern custom properties & Flex/Grid)

## 🏁 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## 📂 Project Structure
```text
src/
├── components/     # Reusable UI components (Layout, Table, Cards)
├── pages/          # Modular page components for each ERP system
├── App.jsx         # Routing and main app entry
├── index.css       # Global design system and theme
└── main.jsx        # Root entry point
```
